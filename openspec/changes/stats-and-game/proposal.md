# Proposal: stats-and-game

## Why

课程大作业要求"通过画图展示数据库中的内容"与"完成一个自制小游戏";同时背单词 APP 的核心玩法闭环(背单词 → 达上限 → 玩游戏赢额度 → 提升上限继续背)依赖本变更落地。

## What Changes

- 新增今日背词情况饼图:以四种颜色展示今日单词熟悉程度分布 —— 绿(熟知,0 次失败学会)、黄(模糊,恰 1 次失败学会)、红(不认识,失败 ≥ 2 次,无论最终是否学会)、灰(待背,今日队列中未背完且失败 < 2 次);扇形角度与数量比例一致,数据全部来自数据库
- 为此修订学习判定:每次点"不认识"将当日失败次数持久化(推翻此前"点击数据仅存内存"的决定,因课程要求图表展示数据库内容);单词学会时随学习记录写入当日失败次数。卡片色块显示仍为会话级,不变
- 新增贪吃蛇小游戏:21×21 网格,蛇从 (11,11) 起步、初始身长 1,界面下方四个方向虚拟按键;撞墙/撞身判负,铺满全部格子判胜;每吃一颗果子 +1 额度,胜利额外 +100 额度
- 新增额度钱包与兑换:额度按用户持久化;玩家可自行决定兑换,1 额度 = 今日上限 +1 词,立即生效并按既有规则补充队列
- 数据库升级 v3 → v4

## Capabilities

### New Capabilities

- `study-stats`: 今日背词熟悉程度饼图的分类规则与展示
- `snake-game`: 贪吃蛇游戏规则(棋盘、操控、胜负判定)与额度奖励获取

### Modified Capabilities

- `word-learning`: 新增"不认识次数持久化"与"额度兑换每日上限"两条需求

## Impact

- `AppDatabaseHelper`:users 表增加 quota_credit 列;新增 word_daily_fails 表;study_records 表增加 fail_count 列;版本升 v4
- word-learning 的判定逻辑改动:点"不认识"时写库(原纯内存逻辑)
- 新建活动:统计界面(饼图)、贪吃蛇游戏界面;主界面增加入口、额度余额与兑换入口
- 新增自定义 View:饼图控件、贪吃蛇棋盘控件(复用进度环的自定义 View 经验,不引入第三方图表库)
