# Proposal: weather-and-location

## Why

课程新增联网功能要求(天气查询/地理位置查询等,并将相关内容存入数据库)。本变更实现"定位 → 按坐标查天气 → 存库 → 展示"的完整链路,满足联网与数据落库两个评分点。

## What Changes

- 新增地理位置查询:通过系统定位获取当前经纬度并在界面显示;定位权限被拒或定位失败(如模拟器无 GPS)时使用默认坐标(上海徐汇 121.44, 31.19)兜底并提示
- 新增天气查询:按经纬度调用网络天气 API,展示今日天气与未来 7 天预报(天气状况 + 最高/最低气温);API 选型在规格中保持中立,实现时优先 Open-Meteo(免注册免 key),不可达则切换高德等备选
- 查询结果持久化:每次天气查询(坐标、时间、预报内容)写入本地数据库;无网络或请求失败时展示最近一次缓存结果并标注时间
- 新增查询历史界面:以列表展示历史查询记录
- 数据库升级 v4 → v5

## Capabilities

### New Capabilities

- `weather-and-location`: 地理位置获取(含权限与兜底)、联网天气查询、查询结果持久化与历史展示

### Modified Capabilities

(无)

## Impact

- `AppDatabaseHelper`:新增 weather_queries 表,数据库版本升 v5
- 新建活动:天气界面(当前位置 + 今日 + 7 天预报)、查询历史界面;主界面增加天气入口
- AndroidManifest 增加 INTERNET 与定位权限声明;定位需运行时权限申请
- 新增网络请求层(子线程执行 + JSON 解析)与 API 适配接口
- 新界面嵌入进度环(既有规格要求)
