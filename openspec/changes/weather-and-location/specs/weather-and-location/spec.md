# weather-and-location 规格(变更增量)

## Purpose

提供联网天气查询功能:获取设备地理位置(经纬度),按坐标调用网络天气 API 查询当地今日天气与未来 7 天预报,查询结果持久化到本地数据库并支持历史查看,满足课程"联网功能 + 数据存库"的要求。

## ADDED Requirements

### Requirement: 获取当前地理位置

系统 SHALL 通过设备定位能力获取当前位置的经纬度并在天气界面显示。定位需要运行时权限;权限被拒绝或定位失败时 MUST 使用默认坐标(东经 121.44°,北纬 31.19°,上海徐汇)继续提供天气查询,并提示用户当前使用的是默认位置。

#### Scenario: 定位成功

- **WHEN** 用户授予定位权限且设备可获取位置
- **THEN** 天气界面显示当前位置的经度与纬度

#### Scenario: 权限被拒绝

- **WHEN** 用户拒绝定位权限
- **THEN** 系统提示使用默认位置,天气查询基于默认坐标(121.44, 31.19)进行

#### Scenario: 定位失败

- **WHEN** 已授予权限但设备无法获取位置(如模拟器无 GPS 信号)
- **THEN** 系统提示使用默认位置,天气查询基于默认坐标进行

### Requirement: 联网天气查询

系统 SHALL 按当前坐标调用网络天气 API,获取今日天气与未来 7 天预报,每日 MUST 至少包含天气状况与最高/最低气温。天气界面 MUST 展示今日天气,并以列表展示未来 7 天预报。网络请求 MUST NOT 在主线程执行。

#### Scenario: 查询成功

- **WHEN** 网络可用且用户进入天气界面(或点击刷新)
- **THEN** 界面显示今日天气(状况、最高/最低气温)及未来 7 天预报列表

#### Scenario: 查询失败提示

- **WHEN** 网络请求失败(无网络、超时或 API 不可用)且本地无历史数据
- **THEN** 界面提示查询失败,请检查网络后重试

### Requirement: 查询结果持久化

每次成功的天气查询 SHALL 将查询坐标、查询时间与预报内容写入本地数据库。

#### Scenario: 查询入库

- **WHEN** 一次天气查询成功返回
- **THEN** 数据库新增一条查询记录,包含坐标、查询时间和预报内容

#### Scenario: 无网络时展示缓存

- **WHEN** 网络请求失败且数据库存在历史查询记录
- **THEN** 界面展示最近一次成功查询的结果,并标注其查询时间

### Requirement: 查询历史

系统 SHALL 提供查询历史界面,以列表按时间倒序展示历史天气查询记录,每条 MUST 包含查询时间、坐标与当日天气摘要。

#### Scenario: 查看历史

- **WHEN** 用户进入查询历史界面
- **THEN** 列表按时间倒序显示历史查询记录

#### Scenario: 无历史记录

- **WHEN** 数据库中没有任何查询记录
- **THEN** 界面提示暂无查询历史
