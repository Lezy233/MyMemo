# study-progress-widget 规格(变更增量)

## Purpose

提供自定义控件「背词进度环」,以圆环形式直观展示用户今日背词进度(已背数量 / 每日上限),并作为统一视觉元素应用在登录后的所有界面中。

## ADDED Requirements

### Requirement: 进度环展示今日背词进度

进度环 SHALL 以环形进度方式显示两个数值:今日已背单词数与当日上限。环的填充比例 MUST 等于 已背数 / 上限;已背数超过上限时 MUST 按满环显示。

#### Scenario: 部分完成

- **WHEN** 用户今日已背 12 个单词,当日上限为 30
- **THEN** 进度环填充 40%,并显示 "12/30"

#### Scenario: 进度为零

- **WHEN** 用户今日已背 0 个单词
- **THEN** 进度环无填充,显示 "0/上限"

#### Scenario: 超出上限

- **WHEN** 今日已背数大于当日上限
- **THEN** 进度环按满环显示,数值如实显示

### Requirement: 进度环应用于所有界面

进度环 SHALL 应用在登录后的每一个界面中,且各界面显示的进度数据一致。

#### Scenario: 切换界面进度一致

- **WHEN** 用户从主界面切换到其他界面
- **THEN** 两个界面中的进度环显示的进度相同

### Requirement: 进度数据来源可替换

进度环的数据来源 SHALL 与控件本身解耦,使后续变更可以在不修改控件绘制逻辑的前提下接入真实背词数据。

#### Scenario: 占位数据展示

- **WHEN** 背词功能尚未实现
- **THEN** 进度环以占位数据(已背 0 / 默认上限)正常显示,不出现错误或空白
